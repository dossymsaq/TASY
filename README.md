# Жеткіз 750 — доставка по Астане

Курьерская доставка посылок **до 2 кг** по **Астане** по фиксированной цене:

| Кто платит | Сумма |
|---|---|
| Продавец (наш клиент) — при оформлении заказа | 750 ₸ |
| Покупатель продавца — онлайн по ссылке или наличными курьеру | 750 ₸ |
| **Сервис получает за одну доставку** | **1 500 ₸** |

Из 1 500 ₸ курьер получает 1 000 ₸ (меняется в `COURIER_FEE`), сервису остаётся 500 ₸.
Цены, оплата курьеру, лимит веса и районы города задаются в `server/config.js`.

## Состав

```
server/   API + база данных (Node.js 22, Express, SQLite) — отдаёт и сайт
web/      сайт: лендинг, кабинеты всех ролей, страница отслеживания /t/КОД (PWA)
mobile/   мобильное приложение iOS/Android (Expo / React Native)
```

## Роли

- **Продавец** — создаёт заказ, платит 750 ₸, отправляет покупателю ссылку (WhatsApp/Telegram), видит статусы и статистику.
- **Покупатель** — по ссылке (без регистрации) или в приложении: статус, оплата 750 ₸, 4-значный код получения.
- **Курьер** — берёт свободные заказы, «забрал у продавца» → «вручить» по коду покупателя; если покупатель не платил онлайн — принимает 750 ₸ наличными. Во вкладке «Мои деньги» видит заработок, наличные на руках и сколько ему должен сервис.
- **Администратор** — выручка и прибыль, заказы, назначение курьеров, отмена с возвратом, сотрудники, блокировка. Расчёты с курьерами: принять сданные наличные, выплатить заработок, история операций.
- **Техподдержка** — чат-обращения (в том числе от гостей со страницы отслеживания) и поиск заказов.

## Telegram-бот: вход и уведомления (бесплатно)

Основной способ входа: человек нажимает «Войти через Telegram», в боте делится номером, и он уже внутри.
Telegram сам подтверждает, что номер принадлежит этому человеку. Чужой пересланный контакт бот не примет.

Через этого же бота бесплатно приходят уведомления:
- **продавцу:** заказ оплачен, курьер едет, забрал, доставлено;
- **покупателю:** ссылка на оплату, курьер в пути, код получения, вручено;
- **курьерам:** новый заказ;
- **поддержке:** новое обращение; **клиенту:** ответ поддержки.

Чтобы получать уведомления без входа, достаточно открыть бота и поделиться номером.

### Как создать бота (2 минуты)

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Введите название, например `Жеткіз 750`.
3. Введите имя пользователя бота, оно должно оканчиваться на `bot`, например `jetkiz750_bot`.
4. BotFather пришлёт **токен** вида `123456789:AAE...`. Это пароль от бота: **никому его не показывайте и не пишите в чат**.

Токен задаётся на сервере при запуске:

```bash
TELEGRAM_BOT_TOKEN=<токен> PUBLIC_URL=https://ваш-домен.kz ADMIN_PHONES=<ваш номер> npm start
```

- `ADMIN_PHONES` — номера, которые при первом входе получают роль администратора (через запятую).
- `PUBLIC_URL` — адрес сайта для ссылок в уведомлениях.

Бот работает через long polling: свой домен или webhook для него не нужны.

## Вход

Три способа: **Telegram** (основной, бесплатный), **SMS-код** (нужен договор с SMS-сервисом) и **пароль** (сотрудники и демо-аккаунты).
Новые покупатели и продавцы регистрируются прямо при первом входе через Telegram или SMS.

- `SMS_MODE=mock` (по умолчанию) — SMS не отправляются, код показывается прямо на экране входа. **Только для разработки.**
- `SMS_MODE=mobizon MOBIZON_API_KEY=...` — отправка через [Mobizon](https://mobizon.kz). Интеграция написана по документации, но на реальном ключе ещё не проверена.

Защита: код действует 5 минут, 5 попыток ввода, повторная отправка не чаще раза в минуту, не больше 5 SMS на номер в час.

## Запуск на Windows без домена и хостинга

Пошаговая инструкция: [WINDOWS.md](WINDOWS.md). Коротко: дважды щёлкнуть `start-windows.bat`.

## Запуск для разработки

```bash
cd server && npm install && npm start      # http://localhost:3000
npm test                                    # тесты полного цикла доставки
```

При первом запуске создаются демо-аккаунты (телефон / пароль):
админ `77000000001 / admin123`, поддержка `77000000002 / support123`,
курьер `77000000003 / courier123`, продавец `77000000004 / seller123`,
покупатель `77000000005 / client123`. **Перед запуском в работу смените пароли или удалите их.**

Мобильное приложение:

```bash
cd mobile && npm install
EXPO_PUBLIC_API_URL=http://<IP-компьютера>:3000 npx expo start   # открыть в Expo Go
npx eas-cli@latest build -p android                              # сборка для Google Play / App Store
```

## Что нужно до запуска в работу

1. **Платежи.** Сейчас `server/payments.js` работает в тестовом режиме: любой платёж проходит. Нужно подключить Kaspi Pay / Freedom Pay / Halyk ePay (договор с банком, ключи, webhook об оплате).
2. **Сервер и домен.** Разместить `server/` на VPS (например, PS.kz или Hoster.kz), подключить HTTPS, делать бэкапы `data.sqlite` (при росте — перейти на PostgreSQL).
3. **SMS:** заключить договор с Mobizon (или другим SMS-сервисом), включить `SMS_MODE=mobizon`. Дальше — уведомления (SMS / WhatsApp / push) о смене статуса.
4. **Юридическое:** публичная оферта, политика конфиденциальности, фискальные чеки (ОФД).
