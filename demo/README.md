# Демо-версия сайта

Собирает сайт из `web/` и сервер из `server/` в набор статических страниц, где сервер работает прямо в браузере
(SQLite через sql.js, данные — в localStorage посетителя). Оплата, SMS и push — тестовые.
Используется для показа сайта без хостинга (страница на claude.ai).

```bash
cd demo && bash build.sh      # результат в demo/out/
```
