# Запуск «Жеткіз 750» на компьютере с Windows

Сервис работает на вашем компьютере. Бесплатный Cloudflare Tunnel даёт ему адрес в интернете, поэтому сайт открывается с любого телефона. Telegram-бот работает в любом случае. Домен и хостинг не нужны.

> ⚠️ Пока компьютер включён и окно сервера открыто, сервис работает. Выключили компьютер — сервис остановился.

## Первый запуск (около 10 минут)

### 1. Скачайте программу
1. Откройте https://github.com/dossymsaq/tasy (войдите в свой аккаунт GitHub).
2. Зелёная кнопка **Code** → **Download ZIP**.
3. Распакуйте архив в удобную папку, например `C:\Jetkiz750`. Правый щелчок по архиву → «Извлечь всё».

### 2. Создайте Telegram-бота
1. В Telegram откройте **@BotFather** → отправьте `/newbot`.
2. Название: `Жеткіз 750`.
3. Имя пользователя должно оканчиваться на `bot`, например `jetkiz750_bot`.
4. Скопируйте **токен**, который пришлёт BotFather (вида `123456789:AAE...`). **Никому его не пересылайте.**

### 3. Запустите
1. В распакованной папке дважды щёлкните **`start-windows.bat`**.
   - Если Windows пишет «Windows защитил ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**.
   - Если Node.js не установлен, скрипт установит его сам. Windows может спросить разрешение, нажмите «Да».
2. Откроется **Блокнот с настройками**:
   - после `TELEGRAM_BOT_TOKEN=` вставьте токен бота;
   - после `ADMIN_PHONES=` впишите свой номер, например `87081301485`;
   - сохраните (**Ctrl+S**) и закройте Блокнот.
3. Через минуту в окне появится:
   ```
   Сервер работает!
   Сайт для продавцов и покупателей:  https://xxxx.trycloudflare.com
   Telegram-бот:                      https://t.me/jetkiz750_bot
   ```
4. Откройте своего бота в Telegram, нажмите «Войти через Telegram» на сайте и поделитесь номером. Вы войдёте как **администратор**.

## Каждый день

- **Запуск:** двойной щелчок по `start-windows.bat`. **Остановка:** закройте окно сервера.
- **Не закрывайте окно** и не давайте компьютеру уснуть: **Параметры → Система → Питание → Переход в спящий режим → «Никогда»**.
- **Автозапуск при включении компьютера:** нажмите **Win+R**, введите `shell:startup`, нажмите Enter. В открывшуюся папку перетащите ярлык `start-windows.bat`: правой кнопкой мыши → «Создать ярлык».

## Важно знать

- **Адрес сайта `…trycloudflare.com` меняется при каждом перезапуске.** Поэтому продавцам удобнее давать ссылку на **Telegram-бота**: она не меняется. Ссылки для покупателей бот присылает всегда с актуальным адресом.
- **Мобильное приложение** в этом режиме не используем: ему нужен постоянный адрес. На телефоне откройте сайт и выберите «Добавить на главный экран». Получится значок, как у приложения.
- **Ваши данные** (заказы, настройки) хранятся отдельно от программы, в папке `%LOCALAPPDATA%\Jetkiz750`. Чтобы открыть её, нажмите Win+R и вставьте этот путь.
  - При каждом запуске делается резервная копия базы в `backups` (хранятся последние 30).
  - Время от времени копируйте эту папку на флешку или в облако.

## Обновление программы

Скачайте новый ZIP с GitHub и замените им папку с программой. Заказы и настройки останутся: они лежат в `%LOCALAPPDATA%\Jetkiz750`.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| Нужно поменять токен или номер администратора | `settings-windows.bat`, затем перезапустить сервер |
| «Telegram-бот не запустился» | проверьте токен в настройках и интернет |
| «Порт 3000 уже занят» | сервер уже запущен в другом окне |
| Не получается войти через Telegram | `create-admin-windows.bat` создаст администратора с паролем, войдите на вкладке «Пароль» |
| Нет адреса в интернете | сайт работает только на этом компьютере (`http://localhost:3000`). Проверьте интернет и перезапустите |
